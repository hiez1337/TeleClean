## Objective
Разработать полностью функционирующее десктопное приложение TeleClean на Python с PySide6 для массового выхода из Telegram-каналов. Приложение должно иметь современный GUI в стиле Telegram (тёмная тема), поддерживать авторизацию через QR-код и номер телефона, и позволять массово выходить из выбранных каналов с прогресс-баром.

## Context
Проект с нуля в директории D:\Telegram Vihoditel. Это новый проект, никакого кода пока нет. Файл .claude/settings.local.json уже существует, git не инициализирован.

Архитектурные решения (утверждены):
- **GUI**: PySide6 (Qt6) — модульная архитектура с разделением GUI и логики
- **Тема оформления**: Telegram-стиль (тёмная) — фоны #17212b, #242f3d, акцент #2ea6ff
- **Авторизация**: QR-код (основной) + номер телефона (запасной) через Telethon
- **Сборка**: PyInstaller → портабельный exe
- **Безопасность**: .env файл для API ID и API Hash (не в git)

Поток работы:
1. **Auth** — QR (основной) или номер телефона + код подтверждения. Telethon сохраняет сессию в .session файл. При повторном открытии — автоматическая авторизация.
2. **Загрузка каналов** — Получение списка диалогов, фильтрация только каналов (не личные чаты, не группы). Пагинация — грузить по 50, подгружать при скролле.
3. **Выбор** — Чекбоксы, поиск по названию, фильтры (все/непрочитанные/мало подписчиков), "выбрать всё на этой странице".
4. **Bulk Leave** — Подтверждение ("Вы уверены? N каналов"), затем последовательный выход с прогресс-баром. Задержки между запросами из-за rate limits Telegram. Кнопка "стоп". Логирование ошибок.

Обработка ошибок:
- Rate limit — пауза, повтор
- Канал недоступен — пропустить, залогировать
- Потеря соединения — переподключиться
- Нет прав на выход — пропустить, залогировать
- Прерывание пользователем — сохранить прогресс

Хранение данных:
- API ID + Hash → .env (исключён из git через .gitignore)
- Сессия Telethon → .session файл рядом с приложением
- Настройки UI → .teleclean/config.json (тема, последние фильтры)
- Лог выхода → .teleclean/leave_history.json (для повторной попытки)

## Target State
К концу разработки должно существовать:

1. **Структура проекта** — все файлы согласно модульной архитектуре (Подход A), с корректными импортами
2. **main.py** — точка входа, запускает QApplication и главное окно
3. **app/core/telegram_client.py** — асинхронная обёртка над Telethon:
   - QR-авторизация (генерация QR, ожидание сканирования)
   - Авторизация по номеру телефона (запрос кода, подтверждение)

   - Выход из канала
   - Сохранение/восстановление сессии
   - Получение статуса авторизации
4. **app/core/channel_manager.py** — менеджер:
   - Загрузка и кэширование списка каналов
   - Фильтрация (поиск, непрочитанные, <N подписчиков)
   - Массовый выход с rate limiting
   - Сохранение прогресса для прерванных операций
5. **app/gui/auth_widget.py** — виджет авторизации:
   - QR-код (отображение QPixmap с QR, таймер обновления)
   - Альтернативный ввод номера телефона
   - Статус: "waiting_for_scan", "waiting_for_code", "authenticated", "error"
6. **app/gui/channel_list.py** — список каналов:
   - Чекбоксы для каждого канала
   - Поиск по названию (фильтрация в реальном времени)
   - Фильтры: все / непрочитанные / <подписчиков
   - Сортировка: по названию / по дате / по подписчикам
   - Пагинация (подгрузка при скролле)
   - Счётчик выбранных каналов
   - Кнопка "Select All" на странице
7. **app/gui/main_window.py** — главное окно:
   - Переключение между auth_widget и channel_list
   - Кнопка "Leave Selected" (меняет цвет на красный)
   - Подтверждение перед выходом
   - Прогресс-бар и лог во время выхода
   - Выбор темы (тёмная/светлая)
   - Меню: настройки, о программе
8. **app/gui/styles/telegram_dark.qss** и **telegram_light.qss** — QSS-темы:
   - Telegram-стиль: #17212b фон, #242f3d карточки, #2ea6ff акцент
   - Скруглённые углы, правильные отступы, hover-эффекты
   - Состояния: normal/hover/selected/disabled
9. **app/models/channel.py** — data-класс Channel
10. **app/services/session_service.py** — сохранение/загрузка сессии
11. **resources/** — иконки и ресурсы
12. **requirements.txt** — зависимости (PySide6>=6.5, telethon>=1.34, qrcode, pillow)
13. **.env.example** — шаблон .env (без реальных ключей)
14. **.gitignore** — игнор .env, .session, __pycache__, .teleclean/, *.pyc, build/, dist/
15. **Модульные тесты** (pytest) в папке tests/:
    - Тесты для channel_manager (фильтрация, массовый выход)
    - Тесты для channel data model
    - Моки для Telethon
    - Тесты для rate limiting
