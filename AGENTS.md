# TeleClean · WinUI

Рабочая ветка WinUI содержит самостоятельный проект C#. Python, PySide6, Telethon и PyInstaller относятся к ветке `python`.

## Поставка

`winui` — ветка по умолчанию и основной продукт. Python остаётся в `python`. Публичный релиз WinUI публикуется с файлом `TeleClean-WinUI-win-x64.exe`. Перед публикацией скачайте однофайловый артефакт CI для целевого коммита и проверьте этот EXE в `--demo` и `--demo-login`. После публикации проверьте ссылку скачивания из README и равенство SHA-256 скачанного файла проверенному артефакту.

## Работа с веткой

Создавайте рабочую ветку от актуальной `origin/winui` и открывайте PR в `winui`. Обновляйте существующий PR, когда меняется та же работа. Дождитесь проверок для последнего SHA перед разрешённым слиянием. После слияния сверьте удалённую `winui` и авторство на GitHub.

Перед коммитом проверьте имя и email Git на уровне репозитория. Используйте подтверждённый адрес своего аккаунта, например GitHub noreply. После push проверяйте привязку профиля GitHub. Сохраняйте исходных авторов и реальные подписи `Co-authored-by`.

## Архитектура

- `src/TeleClean.Core` содержит модели, WTelegramClient 4.4.8, конфигурацию, кэш и последовательный движок массовой обработки.
- `src/TeleClean.App` использует .NET 8, WinUI 3 из Windows App SDK 1.5 и CommunityToolkit.Mvvm. Из фоновых задач обновляйте представления через `IDispatcherService`.
- `src/TeleClean.Tests` содержит штатный набор xUnit с фейковыми сервисами. Проекты в корневом `tests/` служат историческими экспериментами и не участвуют в WinUI CI.

Telegram ID хранится как `long`. Для сопоставления строк учитывайте тип вместе с ID. Для фотографий используйте `DialogItem.AvatarCacheKey`, разделяющий пространства пользователей, групп и каналов. Для дат сообщений сопоставляйте тип и ID собеседника вместе с ID сообщения.

## Сборка и проверка

Из корня checkout на Windows x64 с .NET 8 SDK и Windows SDK выполните:

```powershell
dotnet test src/TeleClean.Tests/TeleClean.Tests.csproj -c Release
dotnet build src/TeleClean.App/TeleClean.App.csproj -c Release -p:Platform=x64
```

Точка запуска: `src/TeleClean.App/bin/x64/Release/net8.0-windows10.0.19041.0/win-x64/TeleClean.App.exe`. NuGet восстанавливает пакеты с nuget.org. Windows CI запускает xUnit и публикует один файл `TeleClean.exe` в артефакте `TeleClean-win-x64`. Для выпуска используйте профиль `WinX64` и проверяйте запуск EXE из пустой папки.

## Безопасная проверка UI

Для проверки скачанного EXE используйте `--demo` и `--demo-login`. Они подменяют `ITelegramService` и используют отдельный временный каталог конфигурации. Проверяйте светлую и тёмную темы, клавиатурный фокус, узкое окно 610×750, выбор и отмену массовой операции. При 1100×750 все восемь каналов контрольного набора должны быть полностью видимы. При сравнении снимков списка и QR используйте одинаковый масштаб и данные. Описывайте, какие сценарии выполнены на фейковых данных и какие проверены только тестами или по коду.

Сохраняйте пользовательские сессии и сторонние изменения. Исключайте из Git API-реквизиты, данные прокси, файлы сессий, метаданные аккаунтов, кэш, журналы и выходные файлы сборки.
