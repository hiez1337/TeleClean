# TeleClean

- Для C#/WinUI создавайте рабочую ветку от актуальной `origin/winui` и открывайте PR в `winui`. Применяйте `AGENTS.md` из этого checkout.
- Для Python создавайте рабочую ветку от актуальной `origin/python` и открывайте PR в `python`. Применяйте `AGENTS.md` из этого checkout.
- `main` хранит навигацию по версиям и исторический исходный код. Обновляйте ссылки на инструкции и сборки в корневом README при изменении маршрутов.
- Перед публикацией сверяйте автора и коммиттера нового коммита, аккаунт активной авторизации и ветку назначения. После push проверяйте привязку нового коммита к профилю через GitHub. Сохраняйте исходную атрибуцию сторонних участников.
- Дождитесь успешных проверок для последнего SHA PR. Слияние и публикация релиза требуют разрешения для текущей задачи.
